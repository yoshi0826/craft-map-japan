# 日本 伝統工芸マップ

日本の伝統工芸品・職人の技を、地図(Leaflet.js)上にプロットして紹介する静的Webアプリです。

## 起動方法

ビルド不要の静的サイトです。ローカルサーバーで配信してください。

```bash
cd craft-map-japan
python3 -m http.server 8321
```

ブラウザで `http://localhost:8321` を開きます。

## 構成

```
craft-map-japan/
├── index.html          # 画面本体
├── css/style.css        # スタイル
├── js/app.js             # 地図描画・検索・フィルタ・詳細表示ロジック
├── data/crafts.json      # 工芸品データ(経済産業大臣指定 伝統的工芸品 全244件を収録)
├── data/crafts_old_42_backup.json  # リニューアル前の手作業データ(42件)のバックアップ
├── data/categories.json  # カテゴリ定義(色・アイコン)
└── images/                # 工芸品の写真を置く場所(任意)
```

## 機能

- 全国244件の経済産業大臣指定伝統的工芸品をLeaflet地図上にマーカー表示(カテゴリ別に色分け)
- 工芸品名・都道府県名・主な製品でのキーワード検索
- カテゴリ(陶磁器・漆器・織物・染物・金工・和紙・木竹工・人形玩具・その他)による絞り込み
- マーカー / リストクリックで詳細パネル(産地・指定年・主な製品・説明文)を表示
- 詳細パネルから産地組合の公式サイト、および出典である「伝統工芸 青山スクエア」の該当ページにリンク

## 工芸品を追加する

`data/crafts.json` に以下の形式でオブジェクトを追加してください。

```json
{
  "id": "一意なID(英数字)",
  "name": "工芸品名",
  "kana": "ふりがな",
  "prefecture": "都道府県",
  "city": "市区町村",
  "lat": 緯度,
  "lon": 経度,
  "category": "ceramics | lacquerware | textile | dyeing | metalwork | paper | woodwork | doll | other",
  "since": "指定年・起源",
  "products": "主な製品（任意）",
  "description": "説明文",
  "association": { "name": "産地組合名", "url": "https://..." },
  "sourceUrl": "https://kougeihin.jp/craft/xxxx/（任意）",
  "image": "images/xxx.jpg（任意。省略するとカテゴリのアイコンが表示されます）"
}
```

## 実際の写真を追加する

1. `images/` フォルダに写真ファイル(例: `arita-yaki.jpg`)を置く
2. `data/crafts.json` の該当項目に `"image": "images/arita-yaki.jpg"` を追加

写真は著作権に配慮し、自分で撮影したもの・利用許諾のあるもの・パブリックドメインの画像のみを使用してください。

## データについて

収録している244件は、経済産業省が指定する「伝統的工芸品」の公式ポータル「伝統工芸 青山スクエア」(https://kougeihin.jp) に掲載されている全品目です。産地・主な製品・指定年月日・産地組合名と公式サイトURLは同サイトの記載をもとにしており、説明文はその内容を要約した独自の文章です(著作権に配慮し、原文の抜粋・転載はしていません)。産地組合の公式サイトURLは、同サイトに実際に記載されていたものだけを掲載しており、記載がない品目にはリンクを付けていません。座標(緯度経度)は市区町村レベルの概算です。
